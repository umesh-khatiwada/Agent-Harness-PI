# PI Harness

PI Harness is a coding agent that helps users by reading files, executing commands, editing code, and writing new files. It operates within a controlled environment and provides a set of tools to interact with the filesystem and run commands.

## Features

- **File Operations**: Read, write, edit files with precision.
- **Command Execution**: Run bash commands to navigate and manipulate the system.
- **Editing Capabilities**: Make exact text replacements in files.
- **Integration**: Designed to work with various skills and extensions for extended functionality.

## Usage

PI Harness is typically used via a chat interface where users can request file modifications, code generation, or system interactions. The agent interprets the user's intent and uses the available tools to fulfill the request.

## Skills

PI Harness can be extended with skills that provide specialized instructions for specific tasks, such as managing cPanel environments, working with InsForge, or analyzing financial markets with TradingView.

For more information, refer to the PI documentation.
